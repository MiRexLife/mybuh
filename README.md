# Учёт ИП · УСН 6%

Личный инструмент для учёта доходов и налога ИП на УСН 6% (без сотрудников, банк — Сбербанк).

## Структура репозитория

- **`index.html`** — сам инструмент, самостоятельная страница (React подключается через CDN, данные хранятся в `localStorage` браузера). Открывается напрямую в браузере или через GitHub Pages.
- **`backend/`** — код сервера для будущей автоматической синхронизации с выписками СберБизнес (сейчас не используется, ручной CSV полностью закрывает задачу). Подробности — в `backend/README.md`.

## Как пользоваться `index.html`

1. Откройте страницу (локально или по адресу GitHub Pages).
2. Во вкладке «Операции» загрузите CSV-выписку из СберБизнес или добавьте операции вручную.
3. Снимите галочки с операций, не являющихся доходом.
4. Во вкладке «Взносы» фиксируйте уплаченные страховые взносы.
5. Во вкладке «Налог» смотрите сумму к доплате перед каждым сроком (28 апреля / июля / октября).

Данные хранятся только в браузере на этом устройстве (`localStorage`). Если открыть инструмент в другом браузере или на другом устройстве, данные не синхронизируются автоматически — это не облачное хранилище.

## Backend (на будущее)

Папка `backend/` содержит готовый Node.js-сервер для автоматической выгрузки операций через API СберБизнес. Требует отдельного хостинга (VPS или PaaS) — GitHub Pages его не запустит, только хранит код. Инструкция по развёртыванию — в `backend/README.md`.
